# Финансовая математика — вариант № 1

## Задание

Создать презентацию с помощью Reveal.js. Там, где это возможно, использовать Markdown и выносить каждый слайд в отдельный файл. Оформление вынести в отдельный CSS-файл. Подготовить не менее 20 слайдов, включая титульный, заключительный и слайды-разделители перед разделами. Обеспечить читаемость, навигацию стрелками, номера слайдов и работающее меню reveal.js-menu с названиями всех слайдов. Не допускать скроллов на слайдах. Использовать локальную версию Reveal.js и включить не менее трёх изображений.

Раскрыть определение финансовой математики, формулы наращения и дисконтирования для простых и сложных процентов, описать три практики начисления процентов. Привести 12 подробно решённых примеров: для каждой практики, каждого вида процентов и каждой операции. Создать на JavaScript таблицу порядковых номеров дней года и программу расчёта кредита для трёх практик и двух видов процентов на срок от 30 дней до 10 лет. Включить исходный код программ и не менее трёх тематических весёлых картинок.

После создания репозитория не удалять его и не переносить сдачу в новый репозиторий. При необходимости быть готовым объяснить спорные места реализации.

## Запуск

Все библиотеки Reveal.js и reveal.js-menu находятся в проекте в папке `plugin/`; установка пакетов и доступ в интернет не нужны. Запустите локальный сервер, поскольку Markdown-файлы загружаются по HTTP. Например, в VS Code откройте папку проекта и выберите **Open with Live Server** для `index.html`. Либо выполните в терминале:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Если команда python не найдена в Windows, попробуйте `py -m http.server 8000`. Стрелки и кнопки переключают слайды, клавиша M и кнопка слева открывают меню. Программы открываются по ссылкам в презентации. Исходный код находится в `js/`; проверки выполняются командой `node test.js` при установленном Node.js.

Используйте существующий репозиторий: скопируйте исправленные файлы в его папку, проверьте изменения через `git status`, затем создайте коммит и выполните push. Не создавайте новый репозиторий.

## Математические допущения

ACT/ACT здесь — сумма фактических долей каждого календарного года (ISDA-подобный подход); ACT/360 — фактические дни / 360; 30E/360 — европейский вариант с заменой 31-го числа на 30-е, без специальной корректировки конца февраля. Интервал включает начальную дату и исключает конечную. Допустимый срок проверяется по фактическому календарю: минимум 30 дней и максимум 10 календарных лет. Если через 10 лет 29 февраля не существует, предельная дата — 28 февраля.

Простая ставка применяется к первоначальной сумме; сложная — эффективная годовая ставка с дробной степенью. Программа моделирует один платёж в конце срока, а не аннуитетный график, и не учитывает комиссии, страховки и промежуточные платежи. Дисконтирование — обратная операция к наращению по тем же параметрам. Таблица доступна по ссылке на отдельной странице; она не создаёт скроллов внутри слайда.

## Структура

slides/ — отдельные Markdown-слайды; css/ — стили; js/ — исходный код программ; assets/ — три локальные SVG-иллюстрации; test.js — проверки расчётов. Имена учащегося и группы замените на титульном слайде slides/01.md.

В архиве сохранены исходные файлы проекта, включая прежние именованные Markdown-слайды. Рабочая версия подключает пронумерованные файлы `slides/01.md`–`slides/34.md`; старые файлы не влияют на показ.
